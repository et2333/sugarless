# Sprint 3 Retrospective
## Successes

- Team communication was strong, with active coordination during integration and testing phases.

- All planned tasks, including module integration and final documentation, were completed within the sprint timeline.

- Git repository structure and standardized documentation increased traceability and reduced confusion.

## Challenges

- Combining multiple modules caused version conflicts.

- There are still some minor bugs in the system that have not been resolved.

- Overlapping coursework limited members’ availability, slowing down debugging and testing efforts.

## Improvements

- Begin integration testing earlier in future sprints to identify compatibility issues sooner.

- Implement CI pipelines for continuous testing and faster feedback on integration errors.

- Introduce individual work logs and sprint time estimates to balance load across members.
