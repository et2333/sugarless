# Sprint 2 Retrospective
## Successes

- The team collaborated efficiently, maintaining steady progress across all assigned components.

- Task ownership was clear, and members consistently met individual deadlines.

- Continuous communication through GitHub and Jira kept the sprint workflow transparent and traceable.

## Challenges

- Integration between backend and frontend modules required additional synchronization time.

- Some tasks lacked sufficient acceptance criteria, leading to minor misunderstandings in implementation.

- Unforeseen bugs emerged during module linking, delaying the testing schedule.

## Improvements

- Define precise acceptance criteria before starting each user story to reduce ambiguity.

- Increase early integration testing frequency to detect cross-module issues sooner.

- Reserve dedicated time in each sprint for debugging and refinement to stabilize progress before the final sprint.
