# Sprint 1 Retrospective Summary

## Successes
- The team started the project quickly and efficiently, completing the setup phase ahead of schedule.
- All members actively participated in discussions and demonstrated strong ownership of assigned tasks.
- Communication was effective, with regular progress updates shared through GitHub and group channels.

## Challenges
- The overall system design was more complex than expected, involving multiple interdependent modules.
- Several implementation details were difficult to complete within the short sprint duration.
- Module integration proved challenging due to tight timing and uneven development progress.

## Improvements
- Break down complex features into smaller, manageable tasks with clear acceptance criteria.
- Hold short, frequent check-ins to synchronize backend, frontend, and database development.
- Begin early testing and partial integration rather than postponing all linking to the final sprint.
- Allocate more time for documentation and code review to ensure consistency and reduce errors.
